# Aplikativni servis (application service)

## Definicija

Aplikativni servis jeste logička softverska komponenta [[Aplikativni sistem|aplikativnog sistema]] koja drugim komponentama pruža određenu funkcionalnost putem servisne komunikacije.

## Primer

U primarnom cloud kontekstu, jedan aplikativni servis obrađuje svoj korak poslovnog toka i pruža rezultat drugim servisima. Isti servis može istovremeno imati više [[Servisna instanca|servisnih instanci]] iza balansera opterećenja.

## Napomene

Aplikativni servis je logička komponenta. Njegovo konkretno pokrenuto izvršenje jeste servisna instanca, a isti servis može istovremeno imati više instanci.
